# The world wise application:
A learning project built with react + vite to display cities and countries on interactive map using Leaflet, with data management via json-server.
 
## Features:
- Interactive map powered by react-leaflet.
- Manage city data using a local json-server api
- well-structured project with components and context api.
- Protected routes and multiple pages (login, pricing, Home, etc...)

### Start the mock server(json-server):
npm run server
